# Portfolio Summary

## Turkish

Unity, C# ve FastAPI kullanarak canlı futbol maç merkezi uygulaması geliştirdim. API-Football entegrasyonu ile canlı maçlar, skorlar, lig filtreleri, maç detayları, istatistikler, olay akışı ve kadro ekranları oluşturdum. API anahtarını backend tarafında güvenli tutarak WebGL/mobile-ready mimari kurdum.

## English

Built a live football match center app using Unity, C#, FastAPI and API-Football. Implemented live fixtures, scores, league filters, match detail pages, statistics, event timeline, lineups, localization and a WebGL-ready client-server architecture with secure backend API handling.
